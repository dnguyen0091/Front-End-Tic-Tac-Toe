# Tic Tac Toe Game

A classic Tic Tac Toe game built with HTML, CSS, and JavaScript as part of The Odin Project JavaScript Course.

## Features

- Interactive 3x3 game grid
- Two-player gameplay (X and O)
- Win detection for rows, columns, and diagonals
- Draw detection when the board is full
- Score tracking for both players
- Automatic game reset after each round
- Responsive design with modern styling

## How to Play

1. Open `index.html` in your web browser
2. Player X starts first
3. Click on any empty cell to place your mark
4. Players alternate turns between X and O
5. First player to get three marks in a row (horizontally, vertically, or diagonally) wins
6. If all cells are filled without a winner, it's a draw
7. The game automatically resets for the next round
8. Scores are tracked and displayed for both players

## Game Rules

- The game is played on a 3x3 grid
- Players take turns placing their mark (X or O) in empty cells
- The first player to align three marks horizontally, vertically, or diagonally wins
- If all nine cells are filled without a winner, the game is a draw
